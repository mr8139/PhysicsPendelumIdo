# Инструкция по работе с приложением PhysicsPendelumIdo

Это приложение предназначено для изучения физики маятника, проведения симуляций и реальных измерений с использованием датчиков смартфона.

## Основные разделы

### 1. Регистрация и Вход
При первом запуске приложения вам необходимо зарегистрироваться или войти в систему. Большинство функций приложения доступны только авторизованным пользователям.
- **Регистрация**: Введите уникальный код пользователя и дату.
- **Вход**: Используйте свои данные для доступа к функциям.

### 2. Симуляция маятника (Animation)
В этом разделе вы можете увидеть визуальную модель математического маятника.
- Используйте ползунок (SeekBar) в нижней части экрана, чтобы изменить длину нити маятника.
- Приложение автоматически рассчитыет период колебаний (T) по формуле $T = 2\pi\sqrt{L/g}$ и отобразит его на экране.

### 3. Измерение с помощью датчиков (Sensors)
Этот инструмент позволяет измерить период реального маятника, используя акселерометр вашего телефона.
- **Как проводить измерение**:
    1. Надежно закрепите телефон на грузе маятника.
    2. Нажмите кнопку **"Start Measurement"**.
    3. Начнется 10-секундный обратный отсчет, сопровождаемый звуковыми сигналами. За это время вы должны привести маятник в движение.
    4. После отсчета начнется автоматическая запись данных. Приложение зафиксирует 5 полных периодов колебаний.
    5. По завершении вы услышите двойной звуковой сигнал.
- **Результаты**: Приложение рассчитает период (T), частоту (f) и расчетную длину маятника (L).
- **Сохранение**: Вы можете сохранить результат измерения в историю, нажав кнопку **"Save Measurement"**.

### 4. Калькулятор и Формулы
- **Calculations**: Позволяет вручную вводить параметры для расчета характеристик маятника.
- **Formulas**: Справочник основных физических формул, используемых в приложении.

### 5. Графики и История
- **Graphics**: Визуализация данных ускорения.
- **History**: Просмотр всех сохраненных ранее измерений.

### 6. Обучающие материалы
- **Videos**: В этом разделе можно найти полезные видеоматериалы по теме физики колебаний.

## Меню управления
На главном экране доступно меню управления, которое позволяет:
- **Info**: Получить дополнительную информацию об авторе и приложении.
- **Back**: Вернуться на предыдущий экран.
- **Logout**: Выйти из текущей учетной записи.
- **Exit**: Полностью закрыть приложение.
